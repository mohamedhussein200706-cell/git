# Git, GitHub och Visual Studio Code – vad är vad?

En enkel förklaring för dig som är ny

---

## 1. Vad är Git?

- Ett program som sparar versioner av ditt projekt
- Du kan alltid gå tillbaka till en tidigare version
- Styrs med kommandon i en terminal

*Tänk "Ångra" – fast för hela projektet och för alltid.*

---

## 2. Vad är GitHub?

- En webbsida där dina Git-projekt sparas
- Gör det lätt att dela och samarbeta

*Git finns på din dator. GitHub finns på internet.*

---

## 3. Repo, commit och push

- **Repo** – en projektmapp som Git håller koll på
- **Commit** – en sparad version av projektet
- **Push** – skickar dina ändringar till GitHub

*Som ett fotoalbum: varje commit är en ny bild.*

---

## 4. Markdown och README

- **Markdown** – ett enkelt sätt att formatera text
- **README** – första sidan man ser i ett repo

*README betyder "läs mig".*

---

## 5. Vad är Visual Studio Code?

- Ett gratis program för att skriva kod
- Kan byggas ut med tillägg, till exempel Live Server
- Command Palette (F1) hjälper dig hitta alla funktioner
- Emmet skriver HTML snabbare åt dig

*Som Word – fast för kod.*

---

## 6. Vad är HTML?

- Bygger upp innehållet på en webbsida
- Rubriker, text, bilder och länkar

*HTML är skelettet.*

---

## 7. Vad är CSS?

- Bestämmer hur webbsidan ser ut
- Färger, typsnitt och placering

*CSS är kläderna.*

---

## 8. Hur hänger allt ihop?

- Du skriver HTML och CSS i VS Code
- Git sparar versionerna
- GitHub delar dem med andra

*Vilken del känns svårast för dig?*
